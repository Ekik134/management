# Менеджмент в профессиональной деятельности РП0

Репозиторий предназначен для хранения выполненных работ по дисциплине, включая ДЗ, работу на уроках, проектные работы иные материалы.

## Описание дисциплины

Изучение даннорй дисциплины направлено на освоение и развитие навыков менеджмента в профессиональной деятельности РПО: умение организовывать работу в командах, управление проектами, определение рисков и иные аспекты деятельности.

## Навигация по работам

| Папка | Содержимое |
| :--- | :--- |
| **домашние задания** | Домашние задания по дисциплине |
| **материалы преподавателя** | Материалы, предоставленные преподавателем: презентации, конспекты |
| **проектные работы** | Выполненные проекты по дисциплине |
| **работа на уроке** | Практические и иные работы, выполняемые на занатиях по дисциплине |
